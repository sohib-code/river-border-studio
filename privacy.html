Privacy Policy

River & Border Studio · effective 23 November 2026

River & Border Studio ("the tool") is a private command-line tool used by the owner of the River & Border YouTube channel to publish and manage that channel's videos. This policy explains what data the tool accesses through YouTube API Services, how it is used, where it is stored and how access can be revoked.

YouTube API Services

The tool uses YouTube API Services. By using the tool you agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

Data the tool accesses

After the channel owner signs in with Google and grants permission, the tool can access:

  • Channel information of the authorized channel: ID, title, handle, statistics and settings.
  • Video information of that channel's own videos: titles, descriptions, tags, privacy status and thumbnails.
  • YouTube Analytics reports for that channel: views, watch time, subscribers, impressions, click-through rate and audience retention.
  • OAuth tokens issued by Google, which let the tool act on the owner's behalf.

The tool does not access other users' channels, private messages, payment information, or viewers' personal data.

How the data is used

  • To upload videos the owner produced and to set their metadata and thumbnails.
  • To show the owner reports about the channel's own performance.

The data is not used for advertising, profiling, or any purpose other than managing the owner's own channel.

Storage and retention

  • Everything is stored only on the owner's own computer. The tool has no server, database or cloud storage.
  • OAuth tokens are kept in a local file and are deleted when the owner revokes access or removes the tool.
  • Analytics data saved for reports is refreshed or deleted within 30 days.

Sharing

Data obtained through YouTube API Services is not sold, rented or shared with any third party. It is sent only to Google/YouTube as part of the API requests the owner initiates.

Cookies and tracking

The tool and this website do not use cookies, analytics trackers or advertising identifiers.

Revoking access and deleting data

Access can be revoked at any time on the Google security settings page: security.google.com/settings/security/permissions. After revocation the stored tokens stop working, and all locally stored data can be deleted by removing the tool's folder. To request deletion or ask a question, use the contact below.

Changes

If this policy changes, the new version will be published on this page with a new effective date.
